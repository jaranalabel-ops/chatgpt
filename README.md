# App Gestión Salón – MVP (Fase 1)

Documentación base para el MVP de agenda de un salón de peluquería. El objetivo es construir una aplicación web responsive que permita crear y gestionar turnos, clientes, servicios y profesionales, con un backend REST y base de datos relacional.

## Contenido

- [docs/mvp-spec.md](docs/mvp-spec.md): Requerimientos detallados, modelo de datos y lineamientos técnicos.

## Estado

Actualmente el repositorio contiene únicamente documentación. No hay código de frontend ni backend implementado todavía.
